# Documentation

This directory groups repository-level documentation that does not belong to a single code or hardware subfolder.

## Included Documents

- `THIRD_PARTY_SOURCES.md`
  Source provenance for firmware dependencies, PCB assets, and 3D models
- `images/`
  Placeholder location for README visuals and publication-supporting screenshots

## Goal

Make the project easier to:

- present
- publish
- hand off
- review
- reproduce
