# PiezoTester V2.0

PiezoTester V2.0 is a custom mechatronic test platform for piezoresistive and piezoelectric sensor evaluation under repeatable electromagnetic loading. The project combines an ESP32-based real-time firmware stack, a desktop control application, custom electronics, and mechanical fixtures into one reproducible research toolchain.

It is not just a “demo rig”. It is a full test bench with closed-loop load estimation, sensor-path calibration, adaptive electromagnet characterization, automated reporting, and hardware revision tracking.

## Why This Repository Matters

PiezoTester V2.0 was built to make experimental work faster, cleaner, and more defensible:

- Repeatable cyclic load generation using an electromagnet-driven actuator
- Real-time acquisition of load-cell and piezoresistive sensor data
- Calibration workflows aligned with the actual firmware implementation
- Adaptive PWM-to-load learning for feedforward-assisted ramp tests
- Standard, ramp, and hysteresis test modes
- Desktop export pipeline for CSV and PDF reports
- Versioned PCB and CAD assets kept next to the code that drives them

## Core Features

- Multi-mode testing: standard, ramp, and hysteresis acquisition
- One-point load-cell calibration with nominal model correction
- Sensor-path resistance calibration using a reference resistor
- Continuous live mass preview in the calibration workflow
- Advanced electromagnet contact calibration with stored contact-state tables
- Learned PWM-to-load map with point insertion, sorting, interpolation, and reuse
- Feedforward-assisted ramp control with bounded correction steps
- Automatic test summary generation with CSV/PDF export support
- Hardware revision history covering PCB and mechanical development

## Technical Highlights

- Nominal load-cell model based on beam capacity, sensitivity, excitation voltage, and analog gain
- Absolute-value load signal handling to avoid negative mass artifacts
- Resistance reconstruction from divider voltage with a calibration factor stored in NVS
- Electromagnet premodel derived from movement/contact thresholds
- Learned actuator model stored as empirical `(PWM, mass)` pairs
- Piecewise-linear feedforward estimate for ramp tests
- Iterative predictive-corrective update in the ramp controller
- Burst acquisition for hysteresis traces at high sample rate

## Recent Project Wins

- A research-grade calibration flow that mirrors the actual firmware math
- On-device learning of electromagnet behavior instead of fixed lookup-only control
- Integrated desktop reporting that produces presentation-ready PDF summaries
- Multiple PCB revisions with local symbol, footprint, and 3D asset preservation
- A repository structure now being shaped to support publication, fabrication, and onboarding
