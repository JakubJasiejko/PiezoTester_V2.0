# PCB

This directory stores the electrical design history of PiezoTester V2.0 in KiCad.

## Available Revisions

- `PCB V2.0`
  Early board revision and legacy project assets.
- `PCB V2.1`
  Intermediate revision with local 3D model integration.
- `PCB V2.2`
  Later revision with fabrication outputs and local symbol / footprint libraries.

## What You Will Find Here

- `.kicad_pro`, `.kicad_sch`, `.kicad_pcb` source files
- Local symbol and footprint libraries
- Local 3D models used by KiCad
- Gerber exports and production artifacts
- Revision-specific backup archives generated by KiCad

## Source Provenance

This repository mixes:

- custom project-specific KiCad symbols and footprints
- vendor-derived assets from SamacSys-style libraries
- SparkFun and Espressif-derived reference models for selected modules
- local fixes applied so 3D models resolve directly from the repository

See [../../docs/THIRD_PARTY_SOURCES.md](../../docs/THIRD_PARTY_SOURCES.md) for the documented origin of the main assets.

## Practical Note

KiCad creates autosaves, lock files, cache files, and backups aggressively during active design sessions. The repository now documents these artifacts explicitly and ignores the transient ones where possible, while preserving revision history that is actually useful.
