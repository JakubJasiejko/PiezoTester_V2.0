# CAD

This directory contains the mechanical design assets for PiezoTester V2.0.

## Contents

- SolidWorks part files (`.SLDPRT`)
- SolidWorks assembly files (`.SLDASM`)
- STEP exports for exchange and review

## Typical Parts

- Electromagnet mounting hardware
- Structural profiles and fixture supports
- Table / specimen support geometry
- Load-cell support parts
- Contact and pressure-transfer parts

## Intent

The CAD side of the project documents how the electrical and sensing stack is physically realized. These files are essential to understanding:

- specimen alignment
- force transmission path
- load-cell mounting
- electromagnet positioning
- fixture repeatability

## Exchange-Friendly Files

Where STEP files are present, they should be treated as the preferred review / sharing format for collaborators who do not use SolidWorks.

## Local Authoring Note

Most files in this folder are project-authored mechanical assets rather than third-party vendor downloads. When a neutral exchange export exists, it is kept next to the native CAD source on purpose.
