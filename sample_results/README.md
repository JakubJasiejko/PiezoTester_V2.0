# Sample Results

This directory contains representative exported artifacts generated by the desktop application during real bench testing.

## Included File Types

- `*.csv`
  Raw or session-level measurement exports
- `*.pdf`
  Human-readable reports generated by the application

## Why Keep These

These files are useful as:

- UI/export regression references
- formatting examples for future reports
- publication-supporting material
- sanity-check material for new contributors

## Recommendation

Keep this folder small and curated. It should show what a good result package looks like, not become a dump of every local experiment.
